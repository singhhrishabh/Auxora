## 🌟 The Vision

Auxora is the active bridge between you and the UAE banking system. It isn't just a guide; it acts on your behalf. Auxora identifies your banking problem, collects your information, generates document checklists, drafts bank emails, writes complaint letters, and escalates to regulators when banks fail. 

**Your problems float in. Solutions flow out.**

---

## ✨ Key Features

### 📊 Unified Banking Dashboard
Your whole banking life on one screen. Every document, every deadline, every status — Auxora tracks it all so you never miss a step.
* **Active Tasks:** Track loan applications, account openings, and complaint resolutions.
* **Status Flags:** Instant warnings for missing documents or AECB report requirements.

### 🛡️ AI Document Verification
Catch problems before the bank does. Auxora pre-checks every document against rigid bank requirements.
* Validates authenticity, dates, and stamps.
* Flags inconsistencies (e.g., salary certificate mismatch with WPS records).

### 🗣️ Multilingual Voice
Chat in any of 9 languages. Auxora detects your language automatically and adapts its vocabulary to your literacy level — ensuring a construction worker receives simpler language than a corporate treasurer.
* Auto-detect — just type naturally.
* Vocabulary adapted to education and technical level.
* Real-time guidance for filing complaints and regulatory procedures.

## 👥 Built for Everyone in the UAE

Auxora is tailored to meet the unique challenges of every demographic:

- **👷 Workers & Labourers:** WPS salary tracking, free MOHRE complaint generation (800-60), and remittance comparisons. Zero jargon, maximum legal protection.
- **🎓 Students:** Step-by-step guides for zero-balance accounts (Liv, Neo, FAB Mobile) without branch visits.
- **🏢 Business Owners:** Guidance on MBR Fund (SME loans), trade license checklists, and VAT registration. 
- **👨‍👩‍👧 Families:** DIFC Will registration workflows, joint account setup, and empathetic guidance for deceased account procedures.

## 🏗️ Architecture & Stack

The repository features a robust modern web architecture:

- **Frontend Core:** Vanilla HTML/CSS/JS with a highly optimized, dynamic UI featuring 3D flow animations and interactive glassmorphism components.
- **Halo-Fintech React App:** A cutting-edge React application built with Vite, TypeScript, and TailwindCSS to provide an immersive dashboard experience.
- **AI Engines:** `auxora-engine.js` and `chat-engine.js` powering the automated response system and document verification logic.

## 🚀 Getting Started

### Local Setup (Vanilla Core)
Simply clone the repository and open `index.html` in your browser. No build steps required for the core visual experience!

```bash
git clone https://github.com/singhhrishabh/Auxora.git
cd Auxora
open index.html
```

### Local Setup (React Dashboard - halo-fintech)
To run the modern React application:

```bash
cd halo-fintech
npm install
npm run dev
```
